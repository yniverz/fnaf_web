# Five Nights at Freddy's - Web Recreation

A faithful, from-scratch recreation of the original *Five Nights at Freddy's* (2014) in plain JavaScript.
It runs entirely in the browser: no build step, no server, no downloads.

**Play it here: https://yniverz.github.io/fnaf_web/**

Every image and every sound in the game is generated by code at runtime (canvas drawing and the Web Audio API).
No assets from the original game are used. The phone calls are original scripts written for this recreation
and delivered through your browser's speech synthesis, with captions.

## What's in the game

- Nights 1-5, the 6th Night, and the custom Night 7 with per-character A.I. levels (0-20).
- Freddy, Bonnie, Chica and Foxy with movement behaviour modelled on the original:
  movement opportunities every few seconds, a 1-20 roll against the A.I. level, Bonnie on the left
  side, Chica on the right, Freddy's linear path and his refusal to move while watched,
  Foxy's four Pirate Cove stages, the camera-check cooldown, his run down the West Hall and his power-draining door bangs.
- Hourly difficulty bumps at 2, 3 and 4 AM, exactly like the original's A.I. table.
- Eleven camera feeds including the audio-only kitchen, a scrolling office with doors, lights,
  the window, button panels, the fan, posters, and the honkable nose on the Celebrate poster.
- Power: usage bars, the 9.6 s per percent drain curve, the power-out sequence with Freddy's
  glowing eyes and the music box, and the chance of surviving to 6 AM in the dark.
- Phone calls on nights 1-5 (the Night 4 call ends badly, the Night 5 call is garbled), with a Mute Call button.
- Jumpscares for every character, the game-over suit, the 6 AM chime and cheer, the paychecks
  after nights 5 and 6, the pink slip after Night 7, the newspaper intro.
- Golden Freddy: the rare poster on CAM 2B, the slumped figure in the office, the crash.
  The 1/9/8/7 custom night easter egg is in too.
- Stars on the menu for beating Night 5, Night 6 and 20/20/20/20.
- Progress is saved in `localStorage`.

## Controls

| Action | Input |
| --- | --- |
| Look around the office | Move the mouse to the left or right edge |
| Raise / lower the monitor | Hover the bar at the bottom of the screen, or press **Space** |
| Switch cameras | Click the buttons on the map |
| Doors and lights | Click the **DOOR** and **LIGHT** buttons beside each doorway |
| Mute the phone call | Click **MUTE CALL** while the monitor is up |
| Fullscreen | Press **F** |

Captions and volume can be changed under *How to Play* on the menu. Touch input works for the basics.

## Mechanics reference

A.I. levels per night, in the order Freddy / Bonnie / Chica / Foxy:

| Night | Levels |
| --- | --- |
| 1 | 0 / 0 / 0 / 0 |
| 2 | 0 / 3 / 1 / 1 |
| 3 | 1 / 0 / 5 / 2 |
| 4 | 1 / 2 / 4 / 6 |
| 5 | 3 / 5 / 7 / 5 |
| 6 | 4 / 10 / 12 / 16 |
| 7 | your choice |

At 2 AM Bonnie gets +1. At 3 AM and 4 AM Bonnie, Chica and Foxy each get +1.
Movement opportunities: Freddy every 3.02 s, Bonnie 4.97 s, Chica 4.98 s, Foxy 5.01 s.
Each hour lasts 89 seconds. Power drains 1% every 9.6 s divided by the number of usage bars.
Foxy's door bangs drain 1%, then 6%, 11%, and so on.

## Running locally

Open `index.html` in a browser, or serve the folder with any static server:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000/`. Audio starts after the first click because browsers require a user gesture.

## Project layout

```
index.html        page shell and script order
css/style.css     layout
js/util.js        helpers, textures, text, save data
js/audio.js       Web Audio synthesizer: every sound effect, loops, music box, speech wrapper
js/chars.js       procedural art for Freddy, Bonnie, Chica, Foxy, Golden Freddy
js/rooms.js       the eleven camera scenes (perspective projector + props)
js/office.js      the office scene, doors, lights, buttons, fan
js/monitor.js     monitor overlay, map and camera buttons
js/ai.js          animatronic behaviour
js/phone.js       phone call scripts and playback
js/night.js       one night of gameplay: clock, power, input, jumpscares, power-out
js/screens.js     menu, warning, newspaper, intro, 6 AM, game over, paychecks, custom night, help
js/main.js        app shell: scaling, input, state machine
```
